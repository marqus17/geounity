# GeoUnity

- **Unity project**: `GeoUnity/` (Unity `6000.6.9f1`, URP 3D, Desktop).
- **Scope**: Metropolitan France 3D geographic reconstruction from IGN Géoplateforme services (WMTS ortho/plan tiles, RGE ALTI elevation, WFS BD TOPO buildings/vectors), with a 2D map sector selector at launch.
- When building gameplay, feel, audio, shell, or live features, load the `craft-game-floors` skill; if it isn't installed, ask the user whether to run `unity skill install <client>` (ask: never run it without a yes).
